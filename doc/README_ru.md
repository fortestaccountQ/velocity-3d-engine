## 🌟 Ключевые особенности

**Velocity 3D Engine** сочетает в себе высокую производительность рендеринга современного C++20 и [Sokol GFX](https://github.com/floooh/sokol) с эргономичной выразительностью Python благодаря [nanobind](https://github.com/wjakob/nanobind).

- **Высокопроизводительное ядро**: Написано на современном C++20 с легковесными абстракциями с нулевыми накладными расходами (zero-overhead), математикой GLM и Sokol GFX (Direct3D 11, Metal, OpenGL).
- **Python-эргономика**: Полноценные биндинги для Python со стабами типов PEP-484 / PEP-561 (`.pyi`) для автодополнения в IDE. Поддержка перегрузки операторов, контекстных менеджеров и распаковки векторов.
- **Физически корректный рендеринг (PBR)**: Рабочий процесс «металл-шероховатость» (Cook-Torrance GGX microfacet specular, диффузное освещение Ламберта, нормалмаппинг Собеля, ambient occlusion и карты свечения emissive).
- **Система скелетной анимации**: Загрузчик скелетов glTF 2.0 с распространением иерархии костей, инверсными матрицами привязки (inverse bind matrices), линейным скиннингом на CPU (linear blend skinning) и смешиванием нескольких анимационных клипов.
- **Конвейер постобработки**: Модульный `EffectComposer` с поддержкой многопроходной постобработки: HDR Gaussian Bloom, тональная компрессия ACES/Reinhard (tonemapping), виньетирование и пользовательские полноэкранные шейдерные проходы на GLSL/HLSL.
- **Инстансированный рендеринг (Instanced Rendering)**: Высокопроизводительный конвейер `InstancedMesh`, способный отрисовывать десятки тысяч динамических экземпляров (например, пояса астероидов, леса) с индивидуальными матрицами трансформации 4x4 и цветовыми оттенками (tint) для каждого инстанса.
- **2D HUD и очередь оверлеев**: Интегрированная очередь ортографического 2D-рендеринга со встроенным растровым атласом шрифтов для отладочной статистики на экране, шкал здоровья и прицелов.
- **Пространственный звук**: Встроенный звуковой движок на базе `miniaudio` для воспроизведения звуковых эффектов, пространственного 3D-затухания и фонового эмбиента.
- **100% покрытие автоматическими тестами**: Комплексный набор из более чем 420 автоматических модульных, интеграционных и нагрузочных тестов, проверяющих безопасность работы с памятью, жизненный цикл дескрипторов и математику рендеринга.

## 🎮 Включенные игровые демо

В директории [`games/`](../games/) репозитория представлены две полноценные автономные демо-игры, демонстрирующие возможности движка:

### 1. Dungeon Crawler (`games/dungeon_crawler.py`)
Action-RPG от третьего лица в темном подземном склепе:
- **Анимированный персонаж игрока**: Полноценная анимированная glTF-модель рыцаря с иерархией костей и анимациями передвижения.
- **Модульное вооружение**: Кастомная 3D-модель палаша с позолоченной гардой, навершием и кожаными ножнами на поясе.
- **Процедурные PBR-материалы**: Каменная кладка стен высокого разрешения, плиточный пол с картами нормалей и сундуки с сокровищами из темного дуба с железной оковкой.
- **RPG HUD**: Полосы здоровья и выносливости в реальном времени, счетчики собранного золота, ключей и реликвий, а также плашка миникарты.
- **Аудио и атмосфера**: Атмосферный саундтрек подземелья, звуки шагов, звуковые эффекты взаимодействия с сундуками и динамическое освещение от факелов.

```powershell
python games/dungeon_crawler.py
```

### 2. Space Combat Arena (`games/space_combat_arena.py`)
Высокоскоростной боевой космический симулятор с 6 степенями свободы (6DOF):
- **Полетная модель звездолета**: Инерционная физика с 6 степенями свободы, тангажем, рысканием, креном и ускорением форсажа.
- **Пояс астероидов**: Процедурно сгенерированное инстансированное поле астероидов различных размеров и ориентаций, отрисовываемое через `InstancedMesh`.
- **Космическое окружение**: Скайбокс с туманностями глубокого космоса, объемные частицы двигателей и физика лазерных снарядов.
- **Авионика кабины**: Научно-фантастический полетный HUD со спидометром, шкалой заряда форсажа, мониторами корпуса и щитов, а также 2D-радаром.

```powershell
python games/space_combat_arena.py
```

## 🛠️ Сборка и установка

### Предварительные требования

- **CMake**: `>= 3.24`
- **Компилятор C++20**:
  - Windows: MSVC 2022 (v143) или Clang-CL
  - Linux: GCC `>= 12` или Clang `>= 15`
  - macOS: Apple Clang `>= 14`
- **Python**: `>= 3.10`
- **Инструмент сборки**: Ninja (рекомендуется) или MSBuild

### 1. Сборка и установка через Python (режим редактирования)

```powershell
# Клонирование репозитория
git clone https://github.com/fortestaccountQ/velocity-3d-engine.git
cd velocity-3d-engine

# Установка зависимостей сборки
pip install scikit-build-core nanobind ninja pytest numpy

# Компиляция ядра C++ и установка биндингов Python
pip install -e . --no-build-isolation
```

### 2. Прямая сборка через CMake

```powershell
cmake -B build -G "Ninja" -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

### 3. Запуск автоматических тестов

```powershell
pytest tests -q
```

## 💡 Быстрый старт

```python
import VelocityEngine as ve

# 1. Инициализация приложения
app = ve.App(
    title="Velocity 3D Engine - Quickstart",
    width=1280,
    height=720,
    clear_color=(0.08, 0.09, 0.12, 1.0)
)

# 2. Настройка камеры
camera = app.camera
camera.set_position(0.0, 2.0, 5.0)
camera.look_at(ve.Vec3(0.0, 0.5, 0.0))

# 3. Добавление направленного и фонового освещения
app.scene.set_ambient_light(ve.Vec3(0.05, 0.05, 0.07))
sun = ve.DirectionalLight(
    color=ve.Vec3(1.0, 0.95, 0.8),
    intensity=2.5,
    direction=ve.Vec3(-0.5, -1.0, -0.5)
)
app.scene.add_light(sun)

# 4. Создание PBR-материала и меша
mat = ve.StandardMaterial()
mat.base_color = ve.Vec4(0.9, 0.2, 0.2, 1.0)
mat.roughness = 0.25
mat.metallic = 0.8

mesh = ve.Mesh.create_sphere(radius=1.0, rings=32, sectors=32)
entity = ve.Entity(mesh=mesh, material=mat)
app.scene.add_entity(entity)

# 5. Запуск цикла приложения
app.run()
```

## 🗺️ План развития и известные ограничения

Поскольку проект находится на стадии ранней альфы, запланирован ряд ключевых архитектурных улучшений:

- [ ] **GPU Compute Skinning**: Переход от текущего линейного скиннинга на CPU к вычислениям в вершинном/вычислительном шейдере GPU для поддержки большого количества скелетных мешей.
- [ ] **Каскадные карты теней (CSM)**: Поддержка каскадов направленного света с несколькими усеченными пирамидами видимости (frustums) для открытых сцен на открытом воздухе.
- [ ] **Кросс-компиляция шейдеров**: Формализация автоматической оффлайн-трансляции GLSL/HLSL/MSL с помощью `sokol-shdc`.
- [ ] **Интеграция физического движка**: Интеграция Jolt Physics или PhysX для симуляции твердых тел и расчета коллизий.
- [ ] **Бэкенды Vulkan и WebGPU**: Добавление поддержки Vulkan и WebAssembly/WebGPU с использованием Sokol GFX.
